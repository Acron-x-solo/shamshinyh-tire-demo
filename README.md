# Шиномонтаж на Шамшиных, 93а

Отдельное демонстрационное предложение сайта мастерской в Новосибирске. Светлый дизайн с кобальтовыми акцентами, интерактивное 3D-колесо, переключение услуг, подбор опубликованной ставки, полный видимый прайс и галерея настоящих фотографий.

Публичный адрес: https://acron-x-solo.github.io/shamshinyh-tire-demo/

## Запуск

Node.js 22 и npm:

```sh
npm ci
npm run dev
```

Фронтенд: http://localhost:5175/. Проект не использует серверную часть, базы данных или секреты. Кнопки записи прокручивают страницу к контактам; визит согласовывается по двум опубликованным телефонам. Копирование запроса имеет ручной вариант, если браузер запрещает доступ к буферу обмена.

## Проверка

```sh
npm test
npx playwright install chromium
npm run test:browser
npm run format:check
npm run build
npm run inspect
```

Проверки браузера охватывают услуги, цены, копирование запроса, фотографии и оригинал прайса, клавиатурный фокус, мобильное меню, небольшие экраны, доступность, потерю WebGL-контекста и уменьшение движения. `inspect` сохраняет скриншоты в `docs/screenshots`.

## Публикация

GitHub Actions собирает сайт при push в `main`. Pages должен использовать source `GitHub Actions`. Workflow сам устанавливает базовый путь по имени репозитория.

Локальная проверка такой же сборки в PowerShell:

```powershell
$env:VITE_BASE_PATH='/shamshinyh-tire-demo/'
npm run build
npm run preview
```

В другом терминале:

```sh
npm run verify:pages
node scripts/verify-pages.mjs https://acron-x-solo.github.io
```

## Данные и фотографии

Основной источник — [карточка мастерской в 2ГИС](https://2gis.ru/novosibirsk/firm/70000001025191287). Входная ссылка пользователя указывала на здание; выбран единственный шиномонтаж внутри него. Адрес: Семьи Шамшиных, 93а. Проверка сведений: 08.11.2026.

В галерее 12 настоящих фотографий из 55 опубликованных, с атрибуцией и ссылкой на оригинал. В социальных карточках используется кадр той же мастерской. Происхождение изображений: `docs/photo-sources.json` и `src/data/photos.js`.

Прайс перенесён с фотографии, загруженной в 2ГИС 17.04.2026: **48 читаемых значений и одна доплата**. Дата действия цен неизвестна, нижняя часть снимка обрезана. Неопубликованные сочетания не рассчитываются. Количество колёс сезонного комплекса в источнике не указано; балансировка и снятие/установка явно обозначены за 4 колеса. Необычная цена 170 ₽ для R18 сохранена как напечатано и помечена для уточнения.

Полные сведения и ограничения: `docs/sources.md`, `docs/source-facts.json`, `docs/prices-transcribed.json`. Ни отзывы, ни гарантии, ни контакты мессенджеров не выдумывались. Сайт обозначен демонстрацией и закрыт от индексации метатегом `noindex,nofollow`.

## Технологии

React 19, Vite 7, Motion, Three.js, Lucide. Шрифты Golos Text и Unbounded размещены локально. WebGL включается отдельным модулем, останавливается вне экрана и в скрытой вкладке, поддерживает вращение, разборку, паузу, уменьшение движения и статическую иллюстрацию при недоступном контексте. Визуальные правила сохранены в `DESIGN.md`.
