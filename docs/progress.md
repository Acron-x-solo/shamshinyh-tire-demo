# Состояние проекта

Новый самостоятельный сайт шиномонтажной мастерской на Семьи Шамшиных, 93а. Старые сайты «Джуманджи» и Black House сохранены.

Готовы светлый кобальтовый дизайн, интерактивное 3D-колесо, переключение услуг с реальными фотографиями, выбор опубликованной ставки, полный читаемый прайс, 12 фотографий с авторами, диалоги, ответы на вопросы, телефоны и маршрут. Все кнопки записи ведут к контактам. Фронтенд работает на порту 5175, сборка с базовым путём репозитория — на 4175.

Проверки и независимый обзор завершены. Создан отдельный репозиторий `Acron-x-solo/shamshinyh-tire-demo`; следующая операция — отправка исходников и проверка публикации GitHub Pages.
